# Dataset attribution

Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection [Dataset]. UCI Machine Learning
Repository. https://doi.org/10.24432/C5CC84.

Source: https://archive.ics.uci.edu/dataset/228/sms%2Bspam%2Bcollection

UCI lists the source dataset under Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

dataset.csv is the team's supplied label/message CSV, renamed from Dataset.csv without
changing its bytes. It has 5,572 rows before processing. The notebook removes exact
duplicates and creates cleaned text and features while preserving original messages.
